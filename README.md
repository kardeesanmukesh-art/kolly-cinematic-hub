# Kollywood Premiere

🎬 Tamil Movie Website — Premium Red & Black

Build a premium, modern Tamil movie discovery website called “KOLLYWOOD”.

Overall Style

Create a dark, cinematic, luxurious UI inspired by the Tamil cinema atmosphere.

Primary colors: Black + Deep Red

Background: almost-black / charcoal

Accent: vibrant cinematic red

White/light-gray text for readability

Use subtle red glow effects

Glassmorphism where appropriate

Smooth animations and transitions

Premium movie-poster focused design

Do NOT make it look like a generic template

Make it feel like a professional entertainment platform

Home Page

Create a stunning homepage with:

Hero Section

Show a large Tamil movie hero banner with:

Movie poster/backdrop

Movie title

Short description

⭐ Rating

Release year

Genre

“Watch Trailer” button

“Add to Watchlist” button

Use a dark gradient overlay so the text is clearly visible.

Navigation Bar

Create a premium sticky navbar:

KOLLYWOOD

Home | Movies | Genres | Top Rated | Watchlist

Right side:

Search icon

Favorite icon

User profile

Navbar should become a mobile hamburger menu on smaller screens.

Watchlist

Users should be able to:

Add movies

Remove movies

View saved movies

Persist watchlist using localStorage

Create a beautiful empty-watchlist state when there are no movies.

Visual Design

Make the website feel massive and cinematic.

Use:

Black background

Deep red gradients

Red neon glow

Large cinematic typography

Rounded movie cards

Subtle shadows

Smooth hover animations

Fade-in animations

Skeleton loading states

Avoid excessive red. Use red mainly for buttons, highlights, borders, icons, and glow effects.

Responsive Design

The website must look excellent on:

Desktop

Laptop

Tablet

Mobile

On mobile, convert movie sections into horizontally scrollable carousels and make the navigation mobile-friendly.

Final Requirement

Make the final website look like a premium Tamil cinema platform, not a basic movie listing website.

The first impression should be:

“🔥 This looks like a professional Kollywood streaming/movie platform.”

Prioritize visual quality, cinematic atmosphere, smooth UX, responsive design, and polished animations.
